# analytics-mfe

Vue 3 + Vite + Pinia — analytics micro-frontend (auth stub in Phase 1).

## Dev

```bash
# terminal 1
npm run api

# terminal 2
npm run dev:analytics
```

Open http://localhost:4400 — login at `/login` with `test@example.com` / `password123`.

## Routes

| Path | View |
|------|------|
| `/` | Home (hello) |
| `/login` | Login |
| `/analytics` | Dashboard stub (requires auth) |
