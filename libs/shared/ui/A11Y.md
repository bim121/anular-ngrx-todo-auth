# Accessibility checklist (shared-ui)

Phase 6.3.3. Verify with axe DevTools + keyboard on `/login` and `/todos`. Contrast is against `_tokens.css` light/dark palettes.

## Cross-cutting

- [x] **Contrast 4.5:1** — text (`--color-text` / `--color-muted`) on `--color-bg` / `--color-surface`; danger/success text on their subtle backgrounds. Primary buttons use white on `--color-primary`.
- [x] **Focus visible** — `:focus-visible` ring (`--color-primary`, 2px offset) on Button, Input, FormField control, Checkbox, Toast close, Modal actions. Mouse click does not leave a persistent ring (`:focus { outline: none }` where needed).
- [x] **Focus order** — DOM order. Modal (CDK Dialog) traps tab inside the pane and restores focus on close. Toast is `aria-live` and not in the tab cycle except the dismiss control.
- [x] **Screen reader labels** — see per component. Interactive icon-only controls have `aria-label`.
